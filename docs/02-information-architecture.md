# Arquitectura de información

## Navegación principal

```text
Inicio
Proyectos
Sobre mí
Experiencia
Contacto
CV
```

En el MVP, `Proyectos`, `Sobre mí`, `Experiencia` y `Contacto` pueden ser secciones de la página principal. Los casos de estudio sí tendrán rutas independientes.

## Rutas

```text
/
/projects/hms-elite
/projects/gasflow
/projects/amr-refrigeracion
/cv.pdf
```

Opcional después del MVP:

```text
/about
/experience
```

## Página principal

### 1. Header

- Nombre o marca personal.
- Navegación corta.
- Botón de CV.
- Menú móvil accesible.

### 2. Hero

Contenido:

- Sebastián Ojeda.
- Backend-Focused Full-Stack Developer.
- Descripción corta.
- CTA principal: Ver proyectos.
- CTA secundario: Descargar CV.
- Enlaces a GitHub y LinkedIn.

### 3. Evidencia rápida

Tres señales verificables:

- Sistemas full stack.
- Aplicaciones móviles operativas.
- QA y arquitectura.

Evitar estadísticas vacías o contadores artificiales.

### 4. Proyectos destacados

Orden:

1. HMS Elite.
2. GasFlow.
3. A-M-R Refrigeración.

Cada tarjeta contiene:

- Tipo de producto.
- Problema.
- Solución.
- Tecnologías principales.
- Estado.
- Captura.
- Caso de estudio.
- Código.

### 5. Cómo trabajo

Proceso compacto:

```text
Entender el dominio
→ Diseñar el flujo
→ Construir la solución
→ Validar calidad
→ Preparar operación
```

### 6. Capacidades

Agrupadas por capacidad, no por una nube de logos:

- Backend.
- Web y móvil.
- Datos.
- QA e infraestructura.
- Sistemas empresariales.

### 7. Experiencia y contexto

- SAP Basis.
- SAP PI/PO.
- Integraciones.
- Procesos operativos.
- Logística.
- Mantenimiento.
- Trabajo interdisciplinario.

### 8. Sobre mí

Texto breve, profesional y orientado al trabajo.

No incluir historia personal extensa.

### 9. Contacto

- Email.
- GitHub.
- LinkedIn.
- Mendoza, Argentina.
- Disponibilidad.

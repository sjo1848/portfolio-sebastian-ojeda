## Ranking for mockup stage

1. **E — Ivory + Petrol + Brass**
2. **A — Stone + Copper**
3. **D — Mineral + Oxide**
4. **F — Parchment + Oxblood**
5. **G — Cream + Midnight + Clay**
6. **H — Limestone + Forest + Ember**

## Rationale

### E — strongest new challenger
Deep petrol differentiates the portfolio from generic charcoal/copper developer sites while preserving technical seriousness. Brass provides a restrained signal color. This should be tested in a real hero/project composition before approval because corporate/fintech drift is the main risk.

### A — safest identity continuity
Still the best evidence-backed evolution of the current UI. It already works with screenshots and the existing night surfaces. Its weakness is familiarity: copper-on-warm-neutral is strong but not especially surprising.

### D — disciplined and mature
Excellent if the desired identity is quiet and industrial. It may need stronger typographic personality to avoid becoming visually flat.

### F — valuable edge case
This is the most authored/editorial option and therefore worth seeing in context. It should not win purely on novelty if recruiter clarity softens.

### G — visually effective but conventional
Good for screenshots and product polish, but closer to familiar product/SaaS branding. Keep as a control option rather than a preferred identity.

### H — coherent but strategically risky
The palette is attractive, but forest/moss signals can unintentionally imply sustainability/outdoor specialization. Not recommended for the first mockup round unless other options fail.

## Required next test

Do not choose from swatches alone. Create the same minimal composition for A, D, E and F:
- brand/name + Full-Stack role;
- one headline/proposition;
- primary CTA;
- one HMS Cloudflare or Alquileres project card with real screenshot;
- status/technical metadata kept minimal.

Evaluate:
- first-viewport recruiter clarity;
- screenshot legibility;
- brand memory;
- perceived technical maturity;
- risk of category misclassification;
- ES/EN portability.

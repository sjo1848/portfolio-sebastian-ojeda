# Cómo trabajo

## 1. Entender el dominio

Identifico usuarios, roles, procesos, restricciones y riesgos antes de elegir una solución técnica.

## 2. Diseñar el flujo

Defino estados, responsabilidades, datos y recorridos de usuario para reducir ambigüedad y deuda temprana.

## 3. Construir la solución

Implemento backend, interfaces, persistencia e integraciones con una arquitectura proporcional al problema.

## 4. Validar la calidad

Incorporo pruebas, seguridad, accesibilidad y revisión de UX como parte del desarrollo, no como tareas posteriores.

## 5. Preparar la operación

Documento, automatizo controles y considero observabilidad, despliegue y recuperación antes de declarar una solución terminada.
